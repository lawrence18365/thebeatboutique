## EVERY POST CHECKLIST

Before hitting publish:

```
[ ] Does this reduce perceived risk of booking us?
[ ] Is there a clear visual hook in first 1 second?
[ ] Does the caption have a hook in the first line?
[ ] Is there a call to action (comment, save, link)?
[ ] Are hashtags included (8-15)?
[ ] Is location tagged?
[ ] Is it scheduled for optimal time?
```

---
